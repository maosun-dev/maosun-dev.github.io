TJA採譜台　利用規約・プライバシーポリシー

1. このツールについて

TJA採譜台は、「太鼓の達人」シリーズの非公式なファンメイドコンテンツです。株式会社バンダイナムコエンターテインメントのファンメイドコンテンツポリシーに沿って、個人が作っています。公式とは関係ありません。

2. してよいこと・禁止すること

◯ 個人で使うこと
◯ リンク（URL）を貼って紹介すること
◯ ツールで作った譜面（TJA）を、作った人が自由に使うこと

✕ このツールのファイルを別の場所にアップロードすること
✕ このツールを改造して配ること

読み込む曲は、自分で使ってよいものを使ってください。

3. 免責事項

このツールは無保証です。ツールを使ったことや、ツールで作った譜面・音源によって起きたことについて、作者は責任を負いません。内容は予告なく変えたり、公開をやめたりすることがあります。達成％などは目安で、本物の太鼓の達人とは同じではありません。

4. プライバシー

このツールは、名前やメールアドレスなどの個人情報を集めません。広告や、アクセスを数える仕組みもありません。

曲や音のファイルは、使っている人のパソコンの中だけで使います。どこにも送りません。

作業中の譜面・設定・差し替えたヒット音は、次に開いたときのために、そのブラウザの中にだけ保存されます。ブラウザの「サイトのデータを削除」で消せます。

文字の形（字体）を Google Fonts から、ページそのものを GitHub Pages から読み込んでいます。そのため、アクセスの記録（IP アドレスなど）は Google と GitHub にも届きます。扱いはそれぞれのプライバシーポリシー（Google・GitHub）に従います。

5. 使っている部品・素材

encoding-japanese（MIT）、wasm-media-encoders（MIT。中の libvorbis・libogg は BSD）、ヒット音は Freesound の Sassaby「Caixa Tarol Rim」・Sorinious_Genious「Rimshot 1.wav」（CC0）。決まりの全文は、ツールの「？ 使い方」の「使っている部品」にあります。
