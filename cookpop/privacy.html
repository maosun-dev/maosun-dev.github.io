クックポッププライバシーポリシー

制定日：2026年10月29日　／　提供者：maosun-dev

1. このポリシーについて

このページは、maosun-dev（以下「開発者」）が提供する iPhone アプリ「クックポップ」で、利用者の情報をどのように扱うかを説明するものです。

2. 開発者が集める情報

開発者は、利用者の氏名・メールアドレス・位置情報などの個人情報を集めていません。

登録した料理（動画のリンク・名前・ジャンル・タグ・メモ）、作った記録、見た目の設定は、利用者の iPhone の中にだけ保存し、開発者に送ることはありません。アプリを削除すると、これらの記録も消えます。機種変更のときは、設定の「バックアップ」から書き出したファイルで移せます。

3. YouTube の動画について

クックポップは、YouTube API サービスを使って、登録した料理動画をアプリの中で再生します。動画は YouTube の公式の埋め込みプレーヤーで、開発者のサイト（maosun-dev.com）のページを通して表示します。動画を再生するとき、YouTube（Google LLC）は、クッキーなどを使って利用者の端末に情報を保存したり、端末の情報を読み取ったりすることがあります。

動画の題名とサムネイル画像は、リンクを登録したときに YouTube の公開の仕組み（oEmbed）から取得します。

クックポップを使うことで、利用者は YouTube の利用規約に同意したことになります。

  • YouTube 利用規約
  • Google プライバシーポリシー

4. 広告について

クックポップでは、Google LLC が提供する広告配信サービス「Google AdMob」を使って、画面の上にバナー広告を表示します。広告の表示のために、次の情報が Google に送られることがあります。

  • 広告識別子（IDFA）…利用者が「トラッキングを許可」した場合のみ
  • IPアドレス、端末の機種やOSのバージョンなどの情報
  • 広告を表示した・タップしたといった利用状況
  • IPアドレスから推定されるおおまかな地域

これらは、広告の配信、広告の効果の測定、不正の防止のために Google が使います。トラッキングを許可しない場合、広告識別子は送られず、利用者の興味にもとづかない広告が表示されます。許可するかどうかは、iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変えられます。

  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
  • Google プライバシーポリシー

5. GitHub Pages の利用について

動画を表示するページは、GitHub, Inc. が提供する GitHub Pages で配信しています。このとき、安全のために GitHub が IPアドレスなどのアクセス記録を保存することがあります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

6. 子どもの利用について

このアプリは13歳未満の子どもを対象としていません。開発者は、13歳未満の子どもの個人情報を意図して集めることはありません。

7. このポリシーの変更

内容を変えるときは、このページで知らせます。大きな変更があるときは、アプリのアップデートの説明でもお知らせします。

8. お問い合わせ

このポリシーやアプリについてのお問い合わせは、サポート・お問い合わせのページの窓口へお送りください。
