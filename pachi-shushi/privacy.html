ワンタップ収支 プライバシーポリシー

制定日：2026年10月8日　／　提供者：maosun-dev

1. このポリシーについて

このページは、maosun-dev（以下「開発者」）が提供するアプリ「ワンタップ収支」（iPhoneアプリ版）で、利用者の情報をどのように扱うかを説明するものです。

2. 開発者が集める情報

開発者は、利用者の氏名・メールアドレス・位置情報などの個人情報を集めていません。

収支の記録、メモ、添付した画像・動画、項目の並び順、表示の設定（ライト／ダーク）は、利用者の端末の中にだけ保存され、開発者に送られることはありません。アプリを削除すると、これらの記録も消えます。

CSVの書き出しを使ったときは、利用者が共有シートで選んだ保存先・送り先にだけファイルが渡されます。

3. 写真・カメラ・マイクについて

記録に画像や動画を添付するときだけ、写真ライブラリ・カメラ・マイクを使います。選んだり撮ったりした画像・動画は端末の中に保存され、外部に送られることはありません。

4. 広告について

このアプリでは、Google LLC が提供する広告配信サービス「Google AdMob」を使って広告を表示します。広告の表示のために、次の情報が Google に送られることがあります。

  • 広告識別子（IDFA）…利用者が「トラッキングを許可」した場合のみ
  • IPアドレス、端末の機種やOSのバージョンなどの情報
  • 広告を表示した・タップしたといった利用状況
  • IPアドレスから推定されるおおまかな地域

広告は、画面の下のバナーと、画像・動画の添付が終わったあとに時々表示される全画面広告です。

これらは、広告の配信、広告の効果の測定、不正の防止のために Google が使います。収支の記録やメモ、画像・動画が広告のために送られることはありません。トラッキングを許可しない場合、広告識別子は送られず、利用者の興味にもとづかない広告が表示されます。許可するかどうかは、iPhoneの「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変えられます。

Google による情報の扱いについては、次のページをご覧ください。

  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
  • Google プライバシーポリシー

5. GitHub Pages の利用について

アプリは起動したときに、広告の表示回数の設定ファイルを GitHub, Inc. が提供する GitHub Pages から読み込みます。このとき、安全のために GitHub が IPアドレスなどのアクセス記録を保存することがあります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

6. 年齢について

このアプリはパチンコ・パチスロの収支を記録するためのもので、18歳未満の方を対象としていません。
